# 08 测试用例与验收

## 1. 测试策略

业务单元测试验证计算、筛选、状态机和引用校验；集成测试使用真实 PostgreSQL 验证所有权、事务、约束与并发；少量 Playwright 用例覆盖主要用户流程。模型大多数测试使用可配置假 provider，不在 CI 调用付费模型。

共享 fixture 使用两个虚构用户 A/B、三个自然日样本、已发布／草稿／过期活动、可控制时间和响应延迟的模型。测试不能依赖真实用户日记。

以下是待执行用例，不是通过记录。

## 2. 功能及风险用例

| 编号／需求 | Given 前置 | When 操作 | Then 预期 |
|---|---|---|---|
| C01／R01 | 匿名浏览器 | 获取 session、带 CSRF 注册并确认成年 | 201、Cookie 旋转、后续可读 me；未确认成年 422 |
| C02／R01 | 有效账号 | 正确／错误密码登录，随后退出重用旧 Cookie | 正确成功、错误统一文案、退出后旧 Cookie 不能访问私有资源 |
| C03／R10 | 已登录且有 session | POST/PUT/PATCH/DELETE 缺 token、错 token 或不允许 Origin | 403 且数据库无变更；正常 token 可用 |
| C04／R03/R10 | A/B 各有日记和任务 | A 修改路径访问 B 的详情、分析、factor、job、活动会话、回顾 | 全部 404，无内容和存在性泄露 |
| C05／R02 | A 登录、AI 关闭 | 选评分与情绪，正文为空保存 | 成功持久化，不调用模型 |

| C09／R03 | 两个页面读取 version=1 | 页面一保存，再用旧 version 保存或删除 | 第二次 409，页面一内容保留 |
| C10／R02 | 未保存草稿 | 刷新同标签页；随后保存、退出或切号 | 可恢复；成功保存/退出/切号后旧草稿不暴露 |

| C15／R04 | 未授权、空正文、已有任务三种情况 | 请求分析 | 分别拒绝授权、422、复用任务；正常保存始终可用 |
| C16／R04 | 假模型返回有效/不存在证据/非法 JSON | 分析 | 有效保存；无效线索剔除；非法结构失败，不显示原始文本 |
| C17／R04 | 已有线索 | 确认、修改、不符合 | 状态正确、修正不覆盖模型原文、不符合排除出确认汇总、回顾失效 |
| C18／R04/R10 | 模型正等待响应 | 编辑或删除来源日记，再释放响应 | 原任务取消，旧分析不能写入或复活 |
| C19／R01/R09 | 模型正执行 | 撤回授权或注销，再释放响应 | 主库清理完成，写回拒绝，重新授权也不复活旧结果 |
| C20／R04 | worker 已领取任务后退出 | 租约过期后另一 worker 接管，旧 worker 延迟回写 | 恢复任务，旧 lease_token 不能写回，只一份有效结果 |
| C21／R04 | 供应商超时、429 或 schema 错误 | 执行和重试 | 可重试错误最多两次；schema 不无限重试；最终明确状态 |
| C22／R05 | 含草稿、过期、场景不符、超时长活动 | 推荐并排除某类型 | 仅返回合格最多 3 条；无候选不放宽限制，不调用模型 |
| C23／R06 | 有活动执行会话 | 暂停继续、负时长、终态后继续、两个页面同时提交 | 合法转换成功；非法输入/状态/版本明确拒绝，不错误累计暂停 |
| C24／R06 | 带 client_request_id 创建活动 | 重复请求、完成后填写或跳过反馈 | 只一个会话；反馈可选，终态与反馈使回顾失效 |
| C25／R08 | 7 天内仅两个记录日，或 AI 未授权 | 生成周回顾 | 统计正确、不调用模型，分别 insufficient/disabled |
| C26／R08 | 满足记录门槛 | 模型正常、失败或引用其它用户 ID | 正常有文字；失败保留统计；越权证据不保存 |
| C27／R08 | 回顾任务执行中 | 新建/补记/纠正/修改反馈/切时区，再返回模型结果 | 旧 data_version 结果拒绝；重建后体现最新输入 |
| C28／R09 | 有多类本人数据 | 导出、超上限导出 | 正常文件为有效 JSON 且仅含本人；不含哈希/token；超限明确失败而非截断 |
| C29／R09 | 有 A/B 和公开内容 | A 注销 | A 私密主库及会话删除，B 与公开内容保持可用，旧 Cookie 401 |
| C30／R10 | 日记含脚本、提示注入及模拟高风险文本 | 渲染与分析 | 文本不执行，系统规则不被覆盖；保护分支只展示审核内容 |
| C31／R10 | 支持资源过期、未审核、无匹配地区 | 查询支持资源 | 不展示无效联系方式，不由模型编造，提供通用文案 |
| C32／R05/R06 | 音频缺失、拒绝播放或网络失败 | 开始活动 | 文字步骤仍可操作，音频不自动播放 |
| C33／R10 | 登录或用户日配额已满 | 再次请求、复用已有结果 | 新请求限流；有效缓存复用不新增付费调用 |
| C34／R10 | 网络断开、401、页面卸载 | 保存、反馈、轮询 | 不假成功，输入保留；401 清私密缓存，卸载停止轮询 |
| C35／R02/R07 | 360px、键盘、200% 缩放、减少动效 | 完成记录、读图表与对话框 | 无横向溢出、焦点可见、文字摘要可读、对话框焦点正确 |
| C36／R10 | 规定数据集、20 并发、假模型 | 请求列表/统计/任务创建 | 按固定环境记录 p95 和错误率；与目标比较，不包含模型执行时间 |

## 3. 必须实现的端到端流程

1. 注册 → 不开 AI → 保存空正文日记 → 编辑 → 趋势 → 删除。
2. 开 AI → 保存正文 → 假模型分析 → 纠正 → 推荐 → 活动执行 → 反馈 → 周回顾。
3. 模型超时 → 页面显示失败 → 仍能保存第二条日记并使用文字活动。
4. 两账号隔离 → 导出 → 撤权 → 注销 → 浏览器后退与旧 Cookie 均不能显示私密结果。

定时器测试使用虚拟时钟，不要求测试真实等待数分钟。竞态测试用 barrier 控制读写次序，避免靠随机 sleep 假装覆盖。

## 4. 内容与模型评估

至少 30 条虚构样本；标注输入、预期允许输出、禁止内容、实际结果、模型与 prompt 版本、人工复核结论。样本包含否定句、比喻与情绪混合，不能只测试容易的正向样例。

引用合法率、结构有效率可自动统计；是否误导、是否过度推断、是否出现危险建议需人工复核。严重问题未解决不得开启试用 AI。

20～30 项活动上线前逐项核查来源、授权、步骤、适用提示及审核期限；支持资源按地区实际核验。空白审核字段或示例 reviewer 不能视为通过。

## 5. 发布门槛

- R01～R10 对应 P0 场景全部通过；无越权、正文泄露、假保存、删除后复活等严重缺陷。
- 静态检查、类型检查、后端集成测试、前端构建及四条端到端流程通过。
- 记录真实测试环境、执行命令、提交版本、通过数与失败数；未执行明确标记“未执行”。
- 同机基准：20 并发、每用户 1000 条虚构记录；非 AI 和任务创建接口 p95 <1 秒。记录机器配置，首次只作为试用基线，不外推生产能力。
- 首次记录可用性测试：至少 80% 试用者无需指导完成，快速记录以 1 分钟内为目标；未达标时记录改进，不伪造指标。
- 备份恢复演练通过，隐私说明与实际模型服务一致，部署无示例口令和演示自动灌入。
