# 05 前端页面与交互

## 1. 路由与导航

| 路由 | 页面 | 访问条件 |
|---|---|---|
| `/login`、`/register` | 登录、注册 | 允许匿名；先建立 session 获取 CSRF |
| `/welcome` | 首次说明、成人确认说明、AI 选择 | 登录后；AI 可跳过 |
| `/` | 今天 | 登录 |
| `/journals` | 日记时间线 | 登录 |
| `/journals/new` | 新建记录 | 登录 |
| `/journals/:id` | 记录详情、分析与纠正 | 本人资源 |
| `/journals/:id/edit` | 编辑记录 | 本人资源 |
| `/insights` | 日历、7／30 天趋势、标签分布 | 登录 |
| `/reviews/:id` | 周回顾详情 | 本人有效回顾 |
| `/care` | 关怀活动库与推荐 | 登录 |
| `/care/activities/:id` | 活动说明 | 登录 |
| `/care/sessions/:id` | 计时、执行、结束反馈 | 本人会话 |
| `/settings` | 账号、时区、AI、隐私与数据管理 | 登录 |
| `*` | 页面不存在 | 不展示其它用户信息 |

底部导航：今天、日记、关怀、我的。桌面端改为侧栏，路由和交互含义不变。记录按钮为主要操作，不遮挡表单和系统安全区域。

## 2. 页面验收说明

### 今天

首屏包含“记录此刻”、今日记录摘要和关怀入口；无记录时说明一句话也可以保存。回顾入口显示记录天数，不生成鼓励连续打卡的负担。最近记录只展示本人摘要。

### 新建与编辑

字段按“当前评分 → 情绪多选 → 可选正文 → 可选事件标签 → 发生时间”排列。正文显示字数；时间默认当前当地时间，补记在同一控件完成。

- 至少选择一种情绪和评分才能提交；未填项旁显示可读错误。
- 自定义情绪/标签使用明确新增入口，限制、去重与服务端一致。
- 保存期间按钮禁用，但不能仅靠禁用避免重复，首次提交生成 client_request_id，网络重试复用它。
- 保存成功跳转详情并清草稿；失败保留表单，提示“尚未保存”。
- 收到 409 时提供“查看最新版本”和“复制我的内容”，不能静默覆盖。
- 日期控件按用户时区显示，提交包含明确偏移；跨时区或夏令时转换必须使用时区库，不能直接拼接固定 +08:00。

### 日记列表

按时间倒序，支持分页、日期、情绪、标签筛选；筛选改变返回第一页。区分“还没有记录”“没有符合筛选的记录”和“加载失败”。删除显示二次确认并说明衍生分析和回顾会更新。

### 日记详情与分析

先展示用户原文与用户标签，再展示分析入口及分析结果，明确标注“AI 整理”。未授权时提供说明和前往设置入口，不能先发送后征求同意。

分析卡状态：`not_requested / submitting / queued / running / succeeded / failed / cancelled / stale`。后两类与任务过期不可显示“完成”。轮询每 2 秒一次，页面隐藏时暂停，恢复时重新查询；离开页面停止轮询但不自动取消服务端任务。

证据片段与原文并排或可展开查看。线索操作为“符合、部分符合、不符合”，编辑区填写用户修正。安全拦截时显示审核支持卡，不展示模型被拦截文本。

### 回顾

默认最近 7 天，可切最近 30 天或选择不超过 31 天范围。显示用户时区、记录条数、记录天数、区间平均、日趋势、情绪及事件标签分布。

没有记录的日期留空，图表线段断开；每个数据点能通过键盘或列表查看日期、记录数、分数。情绪多选百分比标注“同一条记录可包含多种情绪”。

生成周回顾时选择连续 7 天；不足 3 个记录日展示基础统计及样本不足说明。未授权 AI 可生成纯统计。回顾失效 404 时说明记录已更新，提供重新生成入口，不把缓存文字继续展示。

### 关怀与执行

推荐表单提供可用时间、当前场景、排除类型，可从某条日记进入。显示最多 3 项活动及规则推荐理由；无结果提示调整条件。

活动开始前展示时长、步骤、适用提示、来源；可选填写活动前评分。音频缺失或播放失败时保留文字步骤。音频必须用户点击后播放，不自动播放。

执行页提供暂停、继续、提前结束、完成。倒计时到零显示“时间到了”，由用户确认完成；刷新页面按服务端会话状态恢复，无法确认离线时段是否执行时提示用户校正，不自动累加后台时长。

结束后反馈全部可跳过，显示“有帮助、一般、不适合”，可填写活动后评分。接口失败保留反馈内容，避免重复创建会话。

### 我的与数据管理

展示账号、时区、AI 状态和隐私入口。撤回 AI 前说明将删除已有分析、用户修正及回顾，可先导出；不影响原始日记。

导出下载 JSON，显示实际成功或失败。注销需输入密码与明确确认，成功清 Session 状态、Query 缓存、sessionStorage 草稿并返回登录页。后台不能继续轮询旧账号任务。

## 3. 组件与模块

| 组件／模块 | 职责 |
|---|---|
| AppShell、BottomNav、ProtectedRoute | 布局、导航和会话加载 |
| MoodScorePicker、EmotionPicker、EventTagPicker | 可访问选择器，复用统一枚举 |
| JournalForm、DraftRecoveryDialog | 记录、草稿、离开保护 |
| JournalCard、FilterBar、Pagination | 列表与筛选 |
| AnalysisPanel、FactorReviewCard、EvidenceQuote | 分析状态及纠正 |
| MoodCalendar、MoodTrendChart、StatisticsTable | 日历、趋势及可访问替代视图 |
| RecommendationForm、ActivityCard、CareTimer | 推荐及活动执行 |
| FeedbackForm、SupportCard、ConfirmDialog | 反馈、审核支持、确认 |
| EmptyState、ErrorState、LoadingState | 通用空态、失败与加载 |

不创建承载全部页面逻辑的超大 App.tsx。组件只处理交互，接口与缓存封装在 feature hooks。

## 4. 缓存失效表

| 操作 | 需要失效的查询 |
|---|---|
| 新建／编辑／删除日记 | journals、journal detail、analysis、insights、reviews |
| 分析成功 | 当前 analysis 与 job |
| 纠正线索 | analysis、reviews |
| 活动终态／反馈 | care session、insights、reviews |
| 时区改变 | me、journals 展示分组、insights、reviews |
| 撤回授权 | me、consents、所有 analysis、reviews、jobs |
| 退出／401／注销 | 清全部用户缓存与草稿，停止轮询 |

Query key 以 `['user', userId, ...]` 开头。浏览器后退不能恢复已删除的私密结果；详情重新校验，未校验前不显示缓存分析。

## 5. 视觉与适配基线

- CSS 变量统一管理背景、文字、边框、强调色、间距与圆角；图表情绪配色不能成为唯一语义。
- 360px 无横向溢出；主要触摸目标至少 44×44 CSS px。
- 字体正文默认 16px，用户放大 200% 仍能完成记录。
- 对话框管理初始焦点、Esc、焦点回归，错误说明与表单字段关联。
- 尊重减少动效偏好；不使用持续跳动、强制音乐或负面情绪刺激动画。
