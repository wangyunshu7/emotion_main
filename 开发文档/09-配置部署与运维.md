# 09 配置部署与运维

## 1. 环境与服务

开发环境可在 Windows PowerShell 运行前后端，PostgreSQL 使用 Docker 或本地服务。生产使用同站入口：Nginx 提供前端静态文件，`/api/` 代理 FastAPI；worker 独立进程，不接受公网请求；数据库不暴露公网。

目标服务：`web / api / worker / db`。API 与 worker 使用同一后端镜像，不同启动命令。迁移作为发布时一次性任务，不让多个进程并发执行。

## 2. 环境变量约定

以下值是模板，不是有效密钥。后续生成 `.env.example` 时只写占位符；实际 `.env` 加入忽略列表。

| 变量 | 默认／例值 | 规则 |
|---|---|---|
| APP_ENV | development | development/test/production |
| APP_BASE_URL | http://localhost:5173 | 生产 HTTPS，与浏览器 Origin 一致 |
| DATABASE_URL | postgresql+psycopg://USER:PASSWORD@localhost:5432/emotion | 只在后端 |
| SESSION_TOKEN_PEPPER | 占位，需随机生成 | 哈希 session 的服务端密钥，至少 32 字节熵 |
| COOKIE_SECURE | false | 本地 HTTP false；生产必须 true |
| SESSION_TTL_SECONDS | 604800 | 固定 7 天 |
| ALLOWED_ORIGINS | http://localhost:5173 | 明确列表，禁用带凭证通配符 |
| AI_ENABLED | false | 默认不开启真实模型 |
| AI_PROVIDER | disabled | disabled/fake/供应商标识 |
| AI_BASE_URL | 空 | 经选型确认的 HTTPS 地址，不能由用户传入 |
| AI_API_KEY | 空 | 服务端密钥，不能用 VITE_ 前缀 |
| AI_MODEL | 空 | 实际部署时固定模型标识 |
| AI_TIMEOUT_SECONDS | 30 | 单次模型请求 |
| AI_MAX_ATTEMPTS | 2 | 单任务最多调用次数 |
| AI_USER_HOURLY_LIMIT / AI_USER_DAILY_LIMIT | 10 / 30 | 创建与调用阶段校验 |
| AI_GLOBAL_DAILY_BUDGET | 0 | 币种由供应商计费配置指定；0 表示禁止真实调用 |
| AI_PRICE_CURRENCY | 空 | 开真模型必须填币种，输入输出单价独立配置 |
| AI_INPUT_PRICE_PER_MILLION / AI_OUTPUT_PRICE_PER_MILLION | 空 | 人工配置并记录核查日期，不假定报价 |
| JOB_LEASE_SECONDS / JOB_HEARTBEAT_SECONDS | 90 / 20 | Worker 租约与续租 |
| CONTENT_ROOT | ./content | 只读取受控目录，禁止路径穿越 |
| BACKUP_RETENTION_DAYS | 7 | 正式上线在隐私说明披露实际值 |
| PRIVACY_LEDGER_ROOT | 私有持久卷路径 | 保存恢复时需重放的删除／撤权事件，不能在前端静态目录 |
| LOG_LEVEL | INFO | 不因 DEBUG 自动打印请求正文 |
| VITE_API_BASE_URL | /api/v1 | 唯一必要的前端接口配置，公开可见 |

配置校验失败应拒绝启动：生产默认密码、缺少 session 密钥、非 HTTPS 生产入口、fake 模型用于生产、真实 AI 开启但缺服务参数/价格/预算等。

## 3. 后续工程的启动约定

下列命令在完成对应代码、Compose 与脚本之后才可运行，当前不是已存在命令的执行记录。每组命令在对应终端工作目录执行；不在启动时隐式灌入演示资料。

### 初始化数据库

在仓库根目录执行；Compose 后续提供开发 db 服务。

```powershell
docker compose -f infra/compose.dev.yml up -d db
```

### 后端与迁移

在 backend 目录执行：

```powershell
uv sync --locked
uv run alembic upgrade head
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### Worker

在独立终端的 backend 目录执行：

```powershell
uv run python -m app.jobs.runner
```

### 前端

在 frontend 目录执行，Vite 代理 `/api` 到 127.0.0.1:8000：

```powershell
npm ci
npm run dev -- --host 127.0.0.1
```

### 内容与演示资料

计划实现的 CLI：

```powershell
uv run python -m app.cli.import_content --path ../content --validate-only
uv run python -m app.cli.import_content --path ../content
uv run python -m app.cli.seed --demo
```

导入工具校验 schema、slug/version、发布审核字段和文件路径；支持重复导入，不清空用户资料。演示 seed 必须在 development/test 且显式 --demo，生产拒绝运行。

## 4. 开发检查与 CI

后端计划命令：

```powershell
uv run ruff check .
uv run ruff format --check .
uv run pytest
```

前端计划脚本：

```powershell
npm run lint
npm run typecheck
npm run test -- --run
npm run build
npm run test:e2e
```

CI 启动隔离 PostgreSQL、运行迁移与关键集成测试、生成 OpenAPI 检查前端类型、执行构建及关键端到端测试。真实模型调用默认关闭。数据库迁移变更检查新库升级及上一发布版本升级；破坏性迁移不以自动 downgrade 假设可恢复。

## 5. 健康检查与任务清理

- `GET /health/live`：进程存活，200；不访问外部模型。
- `GET /health/ready`：数据库可访问且迁移版本匹配，成功 200，未就绪 503；不返回连接串。
- worker 每 20 秒更新受控心跳记录或健康文件；超过 120 秒无心跳告警。
- 每分钟扫描过期租约与到期任务；租约校验防止旧 worker 写回。
- 每天清理过期 session、终态超过 7 天的任务元数据；业务结果不随任务清理而删除。
- 每天检查活动和支持资源审核期限，到期自动退出推荐/展示，并提示维护人员复核；首版不自动向外发送消息。

## 6. 发布流程

1. 固定提交、依赖锁与镜像版本，完成 08 的验收记录。
2. 核实隐私说明、AI 开关、供应商、活动审核、音频授权和支持资源。
3. 创建并验证可恢复备份。
4. 停止旧 worker 领取新任务，等待短任务结束或让租约安全过期。
5. 一次性执行 Alembic 迁移，部署 API、worker 和前端。
6. 检查 ready、匿名 session、登录、保存、统计、推荐以及假模型或受控真实调用冒烟测试。
7. 观察错误率、队列积压、取消及模型费用，保留实际发布记录。

回滚优先回滚兼容数据库的应用版本；涉及破坏性数据变更时使用恢复方案，不能直接运行未验证的降级脚本。恢复会覆盖状态，必须确认恢复点和数据损失范围后实施。

## 7. 备份、删除与恢复

- 试用默认每日备份、保留 7 天；备份加密、访问受限，密钥与备份分离。
- 试用恢复目标：RPO 不超过 24 小时、RTO 4 小时；属于待演练目标，不是当前已兑现服务承诺。
- 应用主库删除即时提交；历史备份在保留期届满后淘汰，隐私说明如实披露。
- 使用独立受限的删除清单记录账号/日记 UUID 与删除时间，不保存正文或邮箱，保留至最后一份可能含该记录的备份过期。清单不通过应用主库回滚，不对普通应用接口开放。
- 首版可采用独立加密持久卷上的事件文件，一事件一 UUID 文件，以临时文件写入、fsync、原子重命名完成持久化；实际落盘失败时不返回删除或撤权成功。先校验权限及密码，再预写事件，随后提交主库清理；如主库提交失败，后台依事件重试并对用户显示待重试，不能丢失已接受的清理意图。未完成事件不受普通保留期清理。
- 从备份恢复时先断开公网、重放删除清单、撤销恢复出的所有 session、取消旧 running/queued AI 任务，再验证数据隔离并开放流量，避免已删除内容重新可见。
- 撤权同样写受限清单，恢复后重放授权状态与结果清理。外部模型历史数据删除按供应商实际能力处理，不承诺不可实现的即时清除。

## 8. 监控与成本

监控请求 p95、5xx、登录限流、队列长度与最长等待、worker 心跳、任务失败/取消、模型耗时、token 和费用。指标使用聚合值；不展示日记正文或按负面情绪给用户排名。

当全局 AI 日预算达到阈值时停止新真实调用，创建分析请求返回可理解限额提示；已请求的周回顾降级纯统计。日记、统计、活动不受模型预算影响。

日志默认保留 7 天，错误追踪也必须脱敏；关闭供应商 SDK 请求/响应正文调试日志。没有凭据时不能为“验证”打印环境变量值。
