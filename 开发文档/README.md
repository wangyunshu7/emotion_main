## 文档优先级

产品目标与首版范围以项目计划为上位依据；业务规则以 01 为准，数据库字段以 03 为准，对外字段及路径以 04 为准，异步处理与模型规则以 06 为准。其余文档引用这些约定，不单独改变它们。发生冲突时先修正文档，再提交实现；不能让前后端分别猜测。

## 首版统一决策

1. React + TypeScript + Vite 前端，FastAPI + SQLAlchemy + Alembic 后端，PostgreSQL 持久化。
2. 同站部署 `/api/v1`；服务端不透明 Cookie Session + CSRF 校验，不在浏览器持久保存访问令牌。
3. AI 处理显式授权、主动触发；日记保存不调用模型。无密钥时可运行基础功能，测试使用确定性的假模型。
4. 日记分析与周回顾使用数据库持久化任务及独立 worker。首版无需引入 Redis/Celery，但任务必须可恢复、可取消。
5. UTC 保存时间，按用户 IANA 时区划分自然日；默认时区 `Asia/Shanghai`。
6. 账号数据默认私密，所有用户资源查询必须限定服务端当前用户。
7. P1 收藏、偏好设置界面、提醒和 P2 多媒体输入不进入首版验收；P0 推荐表单仍提供本次时间、场景与类型排除条件。

## 编码入口

先完成任务 T01～T03，再实现“注册登录 → 保存日记 → 基础回顾”，最后接入 AI、活动反馈与周回顾。任务定义见 [07](07-开发任务与里程碑.md)，可复制的编码任务见 [10](10-AI编码任务提示词.md)。

每次提交关联需求编号和测试编号。任务表保留初始规划；当前任务落实情况见代码实现说明。文档中的示例与预期不能视为真实内容已审核或生产环境已验收。
