# 01 需求基线与业务规则

## 1. 范围与需求编号

| 编号 | P0 需求 | 完成表现 |
|---|---|---|
| R01 | 账号与隐私 | 成人使用确认、注册登录退出、单独授权或撤回 AI |
| R02 | 情绪记录 | 多情绪、1～5 分、可选正文、事件标签、补记、草稿 |
| R03 | 日记管理 | 列表、详情、编辑、删除、日期与标签筛选 |
| R04 | AI 整理与纠正 | 摘要、有证据的可能线索、可确认修改忽略 |
| R05 | 关怀推荐 | 从审核内容库按时间、场景、类型筛选，返回推荐理由 |
| R06 | 活动与反馈 | 开始、暂停、继续、提前结束、完成、可选感受反馈 |
| R07 | 情绪回顾 | 日历、近 7／30 天趋势、情绪与事件标签分布 |
| R08 | 周回顾 | 确定性统计、样本不足说明、可选 AI 回顾文字 |
| R09 | 数据控制 | 导出、单条硬删除、注销及衍生结果处理 |
| R10 | 安全与韧性 | 数据隔离、授权、异常降级、审核后的支持入口 |

P1：收藏、长期偏好编辑界面、主动开启的提醒。P2：语音、图片、设备数据、更长周期分析。暂不做社区、咨询交易、诊断、药物建议、实时监护或复杂聊天陪伴。

## 2. 角色

- 用户：只访问自己的私密资料及已发布活动。
- 内容维护人员：通过受控 CLI 导入和审核活动、支持资源；首版没有 Web 管理后台，也不能通过维护工具读取用户日记。
- Worker：用受限服务身份处理任务，提交结果前再次检查用户、授权和数据版本。

注册必须明确确认年龄已满 18 岁；首版使用自我声明，不收集完整出生日期。使用条款版本、隐私说明版本与 AI 授权版本分别记录。

## 3. 数据与输入规则

| 字段 | 规则 |
|---|---|
| email | 去除首尾空格、统一小写，最长 254；首版不承诺邮件验证或邮件找回功能 |
| password | 12～128 个字符，不截断，不记录日志；仅保存 Argon2id 哈希 |
| nickname | 可选，1～30 字符；空白转为 null |
| timezone | 有效 IANA 时区，默认 `Asia/Shanghai` |
| mood_score | 必填整数：1 很不好、2 不太好、3 一般、4 还不错、5 很好；不是疾病严重程度 |
| emotions | 1～5 个去重条目；内置 code 或 custom code+label |
| body | 可为空字符串，最多 10000 个 Unicode 码点 |
| event_tags | 0～5 个去重条目；内置 code 或 custom code+label |
| occurred_at | 带时区 ISO 8601；可补记，不晚于服务端当前时刻 5 分钟 |
| custom label | 去首尾空格，1～20 字符；code 固定 `custom`，按 label 去重 |

内置情绪 code：`happy / calm / sad / anxious / angry / tired`；标签 code：`study / work / family / relationship / sleep / physical / other`。展示文案与 code 分离。内置条目不接受客户端改名；服务端返回统一 label。

不将日记正文作为 HTML 渲染。不把模型推测标签自动写回用户标签。

## 4. 日记与草稿

- 保存和模型分析是两个独立操作，未授权也能使用全部基础记录功能。
- 一天可有多条记录；默认按 `occurred_at DESC, id DESC` 排序。
- 编辑使用 `version` 乐观锁，冲突返回 409，不覆盖另一个页面的新版本。
- 创建使用客户端生成的 `client_request_id` 去重，断网重试仍只创建一条。
- 草稿首版仅保存在当前浏览器标签页 `sessionStorage`，key 含用户 ID；页面恢复时询问是否恢复。明确提示关闭标签页或清理浏览器可能丢失；不承诺跨设备。
- 草稿包含私密正文，退出、401、切换账号、注销及成功保存后清理本账号草稿。离开未保存页面需提示。

## 5. 统计口径

所有时间点在数据库使用 `timestamptz`，UTC 交换；用户时区保存在独立字段。自然日边界按用户 IANA 时区换算为 UTC 查询边界，不能固定减 8 小时。

- 接口日期范围 `start_date/end_date` 均包含，跨度最多 31 天；默认取用户当地今天及前 6 天。
- 每日分数：当日日记 `mood_score` 算术平均，返回一位小数；图表取该值。
- 区间平均：全部日记评分的算术平均，返回一位小数，不对每日平均再次平均。
- 记录天数：区间内有至少一条记录的自然日数；记录条数另算。
- 无记录日：`entry_count=0, mean_score=null`，图表断开，不能补 0 或 3。
- 情绪占比：含该情绪的记录数／区间总记录数，多选总占比可超过 100%；自定义按 label 区分。
- 标签分布：每个标签涉及的记录数；不标注为“真实原因”或风险等级。
- 活动反馈：完成数与有效反馈数分别展示；缺少前后任一评分时不计算分差。仅描述用户反馈，不推断疗效。
- 更改用户时区时清除图表缓存，使旧周回顾失效，按新时区重算。

## 6. 分析与周回顾

单条分析要求当前有效 AI 授权且日记正文非空；仅结构化记录可以保存和参与统计，但不能凭空生成原文证据。

线索反馈状态：`unreviewed / matches / partial / rejected`。用户编辑的线索另存 `user_text`，保留模型原文供本人查看；只有 `matches/partial` 线索可进入“用户确认线索”汇总。

周回顾日期为用户选择的连续 7 个自然日（起止均包含），默认最近 7 天，可包含当天，注明“统计截至生成时”。

- 任何样本数都可生成程序统计。
- 有记录日期不足 3 天时，`insight_eligible=false`，不调用跨日关联模型，只给统计与样本不足说明。
- 满足门槛但未授权时，仍返回统计，`narrative=null`。
- 每条 AI 回顾线索必须关联具体记录或程序统计字段。关联不等于因果，不给疾病结论。

## 7. 推荐与执行规则

本次推荐条件：`available_minutes` 为 1～60 整数；`scene=home/office/outdoor/any`；`excluded_types` 为活动类型数组；可选 `journal_id`。长期偏好界面属于 P1。

先过滤 `published`、未过审核期限、时长不超过可用时间、场景匹配、未排除类型，再确定性排序返回最多 3 个候选。无候选时返回空列表和调整条件提示，不悄悄放宽限制。

活动类型：`mindfulness / music / movement / writing / daily_care`。已发布活动必须有文字步骤；音频为可选增强，无可用授权音频时用文字引导，不伪造播放资源。

执行状态：`running → paused → running → completed`，`running/paused → stopped`。终态不可继续转换；新一轮活动需新建会话。

前端计时用单调时钟加后台恢复校准；后端校验上报时长为非负且不超过开始至今的墙钟时长加 5 秒容差。暂停不计入有效活动时长，不自动将倒计时结束记为用户完成。

反馈在 `completed/stopped` 后可选填写：`helpfulness=helpful/neutral/not_suitable`，前后评分各 1～5 或 null，备注最多 500 字。未完成和没有改善均不作负面评价。

## 8. 失效与删除规则

| 事件 | 原始记录 | 单条分析 | 周回顾 | 在途任务 |
|---|---|---|---|---|
| 编辑日记 | version +1 | 删除旧结果 | 删除该用户全部缓存回顾 | 取消该条分析及该用户回顾任务 |
| 删除日记 | 硬删除 | 级联删除 | 删除该用户全部缓存回顾 | 同上，迟到结果不可回写 |
| 纠正线索 | 日记不变 | 更新反馈 | 删除全部缓存回顾 | 取消该用户回顾任务 |
| 修改活动终态或反馈 | 日记不变 | 不变 | 删除全部缓存回顾 | 取消该用户回顾任务 |
| 修改时区 | 保留 | 保留 | 全部删除 | 取消回顾任务 |
| 撤回 AI 授权 | 保留 | 删除 AI 结果及其用户修正 | 删除回顾，可重新请求纯统计 | 取消全部 AI 任务 |
| 注销 | 用户及私密数据硬删除 | 删除 | 删除 | 取消或级联删除，迟到结果被拒绝 |

撤回授权前解释会删除对应分析与修正，用户可先导出。重新授权不自动恢复或重跑。任何删除只承诺应用主库与在线衍生数据即时处理；备份和外部服务按已披露策略处理，不能宣称即时全网抹除。

## 9. 非功能目标

- 目标负载：首轮试用 10～20 人；以 20 并发用户进行基础验收，不当作容量上限。
- 本地同机测试基准下，非 AI 请求 p95 小于 1 秒；AI 创建任务接口 p95 小于 1 秒，不含任务执行。
- 单次模型请求超时 30 秒，任务最多执行 2 次，前端不无限等待。
- 360px～1440px 宽度可使用；键盘操作有焦点，图表提供文字摘要，颜色不单独表达情绪。
- 产品界面简洁友好，不设置断签惩罚、负面排名、诊断标签或疗效承诺。
