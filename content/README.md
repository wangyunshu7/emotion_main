# 内容管理

`activities/drafts.json` 包含 25 项原创开发草稿，均为 draft，不能作为完成审核的正式内容。导入不会自动发布。

完成步骤、适用提示、真实来源与授权核查后，由维护者填写 reviewer、reviewed_at、review_due_at，将状态改为 published，再通过受控导入工具入库。已发布版本不可原地改写，变更使用新版本 slug 并归档旧版本。

本地 `seed --demo` 可显式创建 3 项标明“开发演示”的联调活动，仅允许 development/test，不能作为生产审核记录。

首版使用文字活动。音频资源未配置授权与允许域名前不会启用播放。地区支持资源不含任何编造的号码，需要实际核验后维护。
